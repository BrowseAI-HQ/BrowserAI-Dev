# LastSearch swag kit

Screen-print-ready artwork. **Two inks only** on dark garments: White + Orange
(PMS 1655 C / hex #F97316). The checkmark inside the mark is a knockout — the
garment color shows through (no third ink).

| File | Placement | Print width | Inks |
|---|---|---|---|
| tee-back-tagline | Full back | 12 in | White + Orange |
| tee-front-chest | Left chest (pairs with the back) | 4 in | White + Orange |
| tee-npx | Center chest (standalone design) | 10 in | White + Orange |

Each design ships as `.svg` (vector source — printers prefer this) and
`-print.png` (300 DPI, transparent background). `-preview.png` files are
garment mockups for approval only — do not print them.

Recommended garment: black or off-black heavyweight tee. The kit assumes dark
garments; for light garments, swap white ink for near-black (#111) — never
change the orange.
